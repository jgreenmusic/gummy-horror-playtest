# Gummy Horror — playtest builds

A co-op first-person horror game about sentient gummy bears trying to escape a haunted candy factory.
Made by Julian Green (Poosic). **Early playtest — expect bugs.**

## Play
1. Download the latest `GummyHorror-vX.Y.Z-windows.zip` from **[Releases](../../releases/latest)**.
2. Unzip it anywhere and run `GummyHorror.exe`. (Windows may warn about an unknown app — More info → Run anyway.)
3. One player clicks **Host online game** and shares the join code. Everyone else types the code and clicks **Join**.

Everyone in a game needs the **same version** — the title screen tells you if a newer one is out.

## Controls
WASD move · Shift run (loud) · Ctrl sneak · Space jump · E eat a gummy · hold E throw a breaker ·
Left mouse bite a friend · M mute mic · Esc menu · **F8 report a bug**

## The goal
Throw every breaker to power the exit, then get out. Eating keeps you alive; eating your friends keeps you
alive *and* costs your sanity. The things in the factory hunt by sound — and they can hear your voice.
